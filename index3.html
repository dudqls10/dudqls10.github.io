01 / Approach

One stack,
four layers.

센서에서 정책까지 — 끊기지 않는 하나의 파이프라인

Why it matters 층마다 담당이 나뉘면 문제가 경계에서 사라집니다. 저는 네 층을 모두 직접 만들어, 센서의 잡음이 제어의 실패로 이어지는 지점까지 추적합니다.

Layer 01

Sensor Hardware

정전용량 센서와 ToF 센서를 하나의 모듈로 통합하고, 로봇별 지지부만 교체해 이식합니다.

Out → Raw capacitance / ToF

Layer 02

Signal Processing

온도 보상, Adaptive EMA, 자체 감지 제거, 불확실성 기반 융합으로 신뢰할 수 있는 거리값을 만듭니다.

Out → Fused distance

Layer 03

Reactive Motion Control

거리값을 RMPflow 제어기에 직접 연결해, 로봇이 주변 물체와 사람에게 실시간으로 반응합니다.

Out → Safe joint command

Layer 04

Learning-Based Manipulation

Diffusion Policy가 작업을 생성하고, 안전 실행 계층이 회피와 작업 복귀를 조율합니다.

Out → Task + safety

각 층의 출력은 다음 층의 입력이 됩니다. 시뮬레이션에서 멈추지 않고 같은 로봇 위에서 네 층을 이어 붙여 동작을 확인했습니다.
