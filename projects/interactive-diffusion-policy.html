Diffusion Policy

Diffusion Policy가 작업 행동을 생성하고, 근접센서 기반 RMPflow가 사람의 접근에 반응해 로봇 동작을 조정합니다. 회피로 학습 분포를 벗어난 이후에는 LPB guidance를 적용해 작업을 다시 이어갈 수 있는 행동 생성을 다루었습니다.

01Problem

회피 이후에도
작업은 계속되어야 합니다.

Diffusion Policy는 시연 데이터에서 작업 행동을 학습하지만, 학습 과정에서 경험하지 못한 사람의 접근에는 즉시 대응하기 어렵습니다. 정지 방식은 충돌 위험을 줄일 수 있지만 작업 흐름을 끊고, 반응형 회피를 적용하더라도 로봇이 시연 궤적에서 벗어나면 정책의 예측이 불안정해질 수 있습니다.

따라서 사람의 접근에 반응하는 것뿐 아니라, 회피로 달라진 상태에서 작업을 다시 이어갈 수 있는 closed-loop 구조가 필요했습니다.

03Real-Robot Integration

정책과 제어기의 역할을
실행 계층에서 분리했습니다.

학습 정책은 작업 목표를 생성하고, 하위 제어기는 RB10의 실제 동작과 근접 회피를 담당하도록 구성했습니다. 정책이 생성한 end-effector reference를 RMPflow에 전달하고, RMPflow가 근접센서 입력을 반영한 관절 명령을 생성합니다.

Policy작업 참조

→
Command관절 명령

HardwareRB10 + 상태 피드백
  • Reference interface정책 출력과 하위 제어기의 명령 형식을 분리해 실행 경로를 비교했습니다.
  • Command ownership동시에 두 프로세스가 로봇팔을 제어하지 않도록 실행 모드별 제어권을 명시했습니다.
  • Paired evidence동일한 관측과 diffusion noise에서 base/guided 행동과 실제 로봇 상태를 함께 기록했습니다.

04Avoidance-Induced OOD

안전하게 피한 뒤,
정책은 낯선 상태에 놓입니다.

RMPflow는 사람의 접근에 반응해 충돌을 피할 수 있지만, 그 과정에서 로봇은 시연 데이터에 포함되지 않은 자세로 이동할 수 있습니다. 이 상태에서 기본 Diffusion Policy를 그대로 실행하면 오차가 누적되거나 작업 경로로 복귀하지 못할 수 있습니다.

→

→

05LPB-Guided Resumption

필요한 순간에만
작업 분포 방향으로 보정합니다.

기본 Diffusion Policy는 고정한 상태에서, 현재 상태가 시연 분포를 벗어난 경우에만 LPB guidance가 개입하도록 구성했습니다. 후보 행동이 예측하는 미래 상태를 expert latent bank와 비교하고, 작업 분포에 가까워지는 방향으로 diffusion denoising을 보정합니다.

  1. 01

    상태 표현

    현재 영상과 로봇 상태를 latent로 변환

  2. 02

    OOD 판단

    Expert latent bank와의 거리 비교

  3. 03

    미래 예측

    후보 행동 이후의 latent 상태 예측

  4. 04

    Guidance

    기준을 넘을 때 마지막 denoising 단계 보정

Frozen policy기본 작업 정책은 다시 학습하지 않습니다.

Threshold gatedOOD 기준을 넘는 경우에만 guidance가 개입합니다.

Closed loop첫 action chunk 실행 후 새 관측으로 다시 계획합니다.

06Recovery-Aware Data

실제 회피 이후의 상태에서
작업 복귀 데이터를 수집했습니다.

RMPflow가 생성한 회피 동작 자체는 학습 데이터에 포함하지 않고, 회피가 끝난 위치에서 작업을 다시 이어가는 시연을 별도로 기록했습니다. 이를 통해 dynamics model이 실제 회피 과정에서 발생하는 off-path 상태와 작업 복귀 방향을 학습할 수 있도록 구성했습니다.

  1. 01일반 작업 시연

    정상 조건의 expert demonstration 기록

  2. 02사람 접근과 회피

    RMPflow가 개입한 회피 구간은 기록에서 제외

  3. 03Off-path 상태

    회피가 끝난 현재 위치에서 원격조작 재개

  4. 04복귀 구간 기록

    작업으로 이어지는 recovery sub-trajectory 수집
