01

Problem

Task를 수행하는 능력과
사람 곁에서 일하는 능력은 다릅니다

Task competence ≠ interaction robustness

시연 기반 정책은 정해진 분포 안에서 복잡한 manipulation을 수행합니다. 하지만 사람이 접근해 RMPflow가 경로를 바꾸는 순간, 로봇은 시연에 없던 상태로 이동합니다. 문제는 충돌 회피 자체보다 그 다음 action을 어떻게 task 맥락 안에서 이어갈지에 있습니다.

02

System

생성·복귀·안전의
역할을 분리했습니다

Frozen policy · Action‑conditioned dynamics · RMPflow

학습된 정책은 작업을 생성하고, LPB는 후보 행동이 만들 미래 상태를 평가하며, RMPflow는 실행 시점의 근접 위험에 반응합니다. 각 모듈의 책임을 분리해 작업 성능과 실시간 안전 제어를 하나의 loop에서 연결했습니다.

Training

작업 정책과 복귀 dynamics를
서로 다른 데이터 역할로 학습

  • Expert demonstrations E기본 Diffusion Policy와 expert latent bank의 기준 분포
  • Original rollouts R정책 실행 중 관측된 실제 상태 전이
  • RMP recovery transitions T회피 이후 작업으로 돌아가는 복귀 상태 전이
  • Action‑conditioned dynamics현재 latent와 후보 action으로 미래 latent를 예측

Closed‑loop deployment

후보 행동을 먼저 평가하고
실행 단계에서 근접 안전을 보장

  • ObserveWorkspace/Wrist RGB와 proprioception을 condition token으로 변환
  • DenoiseDiffusion decoder가 horizon action 후보를 반복적으로 정제
  • Guide예측 미래 latent의 expert‑bank 거리를 action gradient로 반영
  • Execute근접센서와 RMPflow가 최종 action을 안전하게 실행

03

LPB Recovery

미래 상태를 예측해
복귀 방향을 만듭니다

Latent prediction · OOD cost · Guided denoising

현재 latent와 후보 action chunk로 미래 latent를 예측하고 expert bank와의 거리를 계산합니다. 그 거리의 gradient를 denoising에 반영해, 회피 이후에도 정책이 전문가 시연 분포 가까이에서 다시 작업을 이어가도록 유도합니다.

  1. 01

    Encode

    RGB와 proprioception을 현재 상태 latent로 변환합니다.

  2. 02

    Predict

    후보 action chunk가 만들 미래 latent를 예측합니다.

  3. 03

    Measure

    Expert latent bank와의 거리를 OOD cost로 환산합니다.

  4. 04

    Guide

    Action gradient를 적용해 마지막 denoising 구간을 보정합니다.

Guided denoising 기본 정책은 고정하고,
필요한 순간의 action sampling만 보정

작업 생성 능력을 보존하면서 회피로 만들어진 분포 밖 상태를 전문가 시연의 latent 분포 쪽으로 유도합니다.

04

Validation

사람 접근부터 재계획까지,
실로봇에서 검증했습니다

Closed‑loop response · Local avoidance · LPB diagnostics

작업 수행 중 사람의 접근, RMPflow의 국소 회피, LPB의 latent/OOD 판단을 실제 실행 타임라인으로 묶었습니다. 외부 동작과 내부 추론이 하나의 closed loop에서 어떻게 이어지는지 확인할 수 있습니다.

Project takeaway

학습 정책이 작업을 만들고, RMPflow가 가까운 위험에 반응하며, LPB가 회피 이후의 낯선 상태를 작업 복귀 문제로 연결합니다.
