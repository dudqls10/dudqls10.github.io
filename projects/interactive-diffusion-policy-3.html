01
Problem

회피 이후에도
작업은 계속되어야 합니다

Demonstration distribution · Human approach · Off-path state

Diffusion Policy는 시연 데이터에서 작업 행동을 학습하지만, 학습 과정에서 경험하지 못한 사람의 접근에는 즉시 대응하기 어렵습니다. 정지는 충돌 위험을 줄이지만 작업 흐름을 끊고, 반응형 회피를 적용하더라도 로봇이 시연 궤적에서 벗어나면 정책의 예측이 불안정해집니다. 그래서 사람의 접근에 반응하는 것뿐 아니라, 회피로 달라진 상태에서 작업을 다시 이어갈 수 있는 closed-loop 구조가 필요했습니다.

03
Guidance

안전하게 피한 뒤,
정책은 낯선 상태에 놓입니다

Avoidance-induced OOD · LPB-guided resumption

RMPflow는 사람의 접근에 반응해 충돌을 피하지만, 그 과정에서 로봇은 시연 데이터에 없던 자세로 이동합니다. 이 상태에서 기본 Diffusion Policy를 그대로 실행하면 오차가 누적되거나 작업 경로로 복귀하지 못할 수 있습니다.

LPB

필요한 순간에만 작업 분포 방향으로 보정합니다

기본 Diffusion Policy는 고정한 상태에서, 현재 상태가 시연 분포를 벗어난 경우에만 LPB guidance가 개입하도록 구성했습니다. 후보 행동이 예측하는 미래 상태를 expert latent bank와 비교하고, 작업 분포에 가까워지는 방향으로 diffusion denoising을 보정합니다.

01

상태 표현

현재 영상과 로봇 상태를 latent로 변환합니다.

02

OOD 판단

Expert latent bank와의 거리를 비교합니다.

03

미래 예측

후보 행동 이후의 latent 상태를 예측합니다.

04

Guidance

기준을 넘을 때 마지막 denoising 단계를 보정합니다.

Frozen
기본 작업 정책은 다시 학습하지 않습니다
Threshold gated
OOD 기준을 넘는 경우에만 guidance가 개입합니다
Closed loop
첫 action chunk 실행 후 새 관측으로 다시 계획합니다
Data

실제 회피 이후의 상태에서 복귀 데이터를 모았습니다

RMPflow가 만든 회피 동작 자체는 학습 데이터에 넣지 않고, 회피가 끝난 위치에서 작업을 다시 이어가는 시연을 따로 기록했습니다. dynamics model이 실제 회피에서 발생하는 off-path 상태와 작업 복귀 방향을 학습하도록 하기 위해서입니다.
